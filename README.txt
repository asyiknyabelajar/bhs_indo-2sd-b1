CARA MENGGUNAKAN
1. Unggah file index.html ini ke folder GitHub Pages yang diinginkan.
2. Buka https://<username>.github.io/<repo>/<folder>/index.html
3. Untuk menampilkan di Blogger, masuk mode HTML dan gunakan kode iframe berikut (ganti URL):
<iframe src="https://USERNAME.github.io/REPO/FOLDER/index.html" title="Bahasa Indonesia II Bab 1 Mengenal Perasaan" style="width:100%;height:85vh;min-height:700px;border:0;border-radius:16px;" loading="lazy" allow="autoplay" referrerpolicy="strict-origin-when-cross-origin"></iframe>
4. Tombol Halaman Sebelumnya dan Berikutnya mengubah halaman digital; hash URL #halaman-01 sampai #halaman-36 dapat dibagikan langsung.
5. Tombol Bacakan halaman memakai suara bawaan browser; kualitas Bahasa Indonesia bergantung pada perangkat dan browser. Mikrofon tidak diperlukan.
6. Latihan pilihan ganda dapat diperiksa otomatis. Jawaban menulis dan berbicara dinilai guru/orang tua.
7. Kemajuan halaman dan hasil latihan disimpan di penyimpanan browser perangkat tersebut (bukan basis data atau Supabase).
